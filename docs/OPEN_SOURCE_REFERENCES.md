Quill is developed as an original codebase. These projects are useful references for product behavior and architecture.

| Project | What Quill studies | License note |
| --- | --- | --- |
| MarkText | Typora-like Markdown writing experience | MIT |
| MarkFlowy | Tauri desktop organization, multiple editing modes | AGPL-3.0 |
| @latentic/live-markdown | CodeMirror 6 live Markdown rendering approach | MIT |
| Joplin | plugin/platform longevity | project-specific licensing; verify before reuse |
| SiYuan | themes, plugins, assets, backlinks/workspace | AGPL-3.0 |
| Foam | Markdown-file-first wiki links/backlinks | verify current repository license before reuse |
| Zettlr | workspace/publishing workflow | GPL-3.0 |

## Contribution rule

Do not paste code from a reference project into Quill merely because it is visible on GitHub.

Before any direct code reuse:

1. identify the exact upstream file and license;
2. confirm compatibility with Quill's license/distribution plan;
3. preserve required notices and attribution;
4. document the reuse in this file or a future NOTICE file.

For AGPL/GPL sources in particular, architecture research should not silently turn into copied implementation code.
